| Windows 10/11 x64 portable | `JackedIN_1.1.0_Windows_x64.zip` |

Verify downloads with `SHA256SUMS`.

## Install

**Windows:** unzip `JackedIN_1.1.0_Windows_x64.zip` and run `jackedin.exe` (scripts use `jackedin.com`). No admin rights are needed. There is no 1.1.0 installer; the 1.0.33 installer is still on the [v1.0.33 release](https://github.com/getpathprobe/jackedin-releases/releases/tag/v1.0.33). It is not code-signed, so SmartScreen may say "Windows protected your PC": choose **More info**, then **Run anyway**.

**Ubuntu / Debian:**
```sh
sudo apt install ./JackedIN_1.1.0_amd64.deb
jackedin --version
```

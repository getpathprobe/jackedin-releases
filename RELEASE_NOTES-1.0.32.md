# JackedIN™ 1.0.32

## One license = one computer, non-transferable

A JackedIN license now activates online once and is then locked to that computer. Activating again on the same computer is allowed; a second computer is refused and needs its own license. There is no deactivate or transfer.

Activate in the app (Enter license, then Activate) or from the command line:

```
jackedin license activate KEY
jackedin license status
```

The free 3-day trial is unchanged. Buy: https://getjackedin.com
